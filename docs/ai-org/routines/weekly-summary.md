# 週次経営サマリ＋AI組織自己点検

実行: 毎週金曜 17:00 JST ／ 出力先: Notion「AI組織 運行ボード」＋Gmail下書き

## 手順

1. **読み込み**: 今週の運行ログ・案件DB・タスクDB・パイプライン・継続率の物差し・
   来週のGoogleカレンダーMTG予定。
2. **週報作成**: 事業責任者が5分で全体を把握できる形で:
   - 納品・進捗ハイライト
   - リスク（締切・健康度🔴🟡）
   - 売上パイプラインの変化（商機と金額）
   - 継続率の物差しの推移
   - 来週の意思決定事項（MTG・承認待ちドラフト）を箇条書き最大5個
3. **ウォッチドッグ（自己点検）**: 今週、日次PM巡回と週次CS/グロース便が
   予定通り運行ボードにログを残しているか確認する。
   抜けがあれば原因を調べ、週報の冒頭に「⚠️AI組織の運行異常」として報告する。
   台帳と現実の乖離が疑われる案件も指摘する。
   （過去にPM自動化が約2週間停止しても誰も気づかなかった教訓による）
4. **記録**: 運行ボードの運行ログに「YYYY-MM-DD（金）週次経営サマリ」見出しで追記。
5. **送付準備**: 同内容を事業責任者宛のGmail下書きにする
   （件名「【AI組織週報】MM/DD週 AI業務効率化支援」、冒頭3行で結論）。
6. **クライアント向け週次報告**: 今週分が未生成の案件があれば、
   クライアント向け進捗報告のコピペ可能文面を生成して運行ボードに記載する。

## ガードレール

- クライアントへの送信はしない
- 金額・契約の決定はしない
